# Ký hiệu hình học (theo SGK Toán Việt Nam – Kết nối tri thức)

| Đối tượng | Viết trong công thức | Không dùng |
|---|---|---|
| Vectơ | `\overrightarrow{AB}` | `\vec{AB}` |
| Góc | `\widehat{ABC}` | `\angle ABC`, `\hat{ABC}` |
| Độ | `60^\circ` | `60°` trong công thức |
| Song song | `a \parallel b` | `a // b` |
| Vuông góc | `a \perp b` | `\bot` |
| Đoạn thẳng, đường thẳng | `AB`, `a`, `(d)` | `\overline{AB}` |
| Mặt phẳng | `(P)`, `(\alpha)`, `(ABC)` | |
| Tam giác | `\triangle ABC` hoặc "tam giác ABC" | |

Trên hình vẽ: góc vuông bằng ô vuông nhỏ, đoạn bằng nhau bằng gạch `|`, `||`, `|||` (`mark: 'eq'…`), song song bằng mũi tên `›`, `››` (`mark: 'par'…`), cạnh bị che bằng nét đứt (hình khối, `solid`).
